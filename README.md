# Insightify - AI-Powered Resume Skill Analyzer

A modern web application that analyzes resumes and provides career insights using NLP and OpenAI APIs.

## Features

- 📄 Resume upload and parsing
- 🤖 AI-powered skill extraction and analysis
- 🎯 Job role matching engine
- 📚 Dynamic learning path recommendations
- 📊 Interactive skill visualizations
- 💼 Career insights and suggestions

## Technology Stack

- **Frontend**: React 18, Tailwind CSS
- **AI Integration**: OpenAI API
- **Charts**: Recharts
- **File Upload**: React Dropzone
- **Icons**: Lucide React

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Majnu04/insightify.git
cd insightify
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
Create a `.env` file in the root directory and add:
```
REACT_APP_OPENAI_API_KEY=your_openai_api_key_here
```

4. Start the development server:
```bash
npm start
```

5. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
